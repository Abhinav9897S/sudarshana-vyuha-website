# सुदर्शन व्यूह · Sudarshana Vyuha — website

Product site for Sudarshana Vyuha by Team ODAX: raw drone and body-cam footage in,
a measured 3D model and a dimensioned floor plan out, fully offline.

A single static page with no build step.

```
index.html            the whole site (styles and scripts inline)
assets/solid_mesh.png reconstruction screenshot used in Results
```

## Run locally

Open `index.html` in a browser.

## Deploy (Render)

New → Static Site → this repo. Build command: empty. Publish directory: `.`

## Editing the team

Names, roles, descriptions and LinkedIn links live in the `TEAM` list near the
bottom of `index.html` (search for `const TEAM`).
